### Carved Lessons
- Credentials are ALWAYS pasted as text, never read from screenshots (cost us the FB app secret + burned OAuth codes twice).
- OAuth codes are single-use; redirect_uri must byte-match; verify via API (curl.exe status codes) before deploying.
- Media rows created BEFORE a FRONTEND_URL change keep the old dead URL — patch DB or re-upload.
- Postiz compose changes require `docker compose up -d postiz`; after Docker Desktop restarts, temporal stack needs manual restart (postgres startup race).
