Seshat Privacy Policy

Last updated: October 10, 2026.

Seshat is a personal, single-user, self-hosted application. It serves no other users.

What Seshat accesses

With the operator's explicit consent through Google sign-in, Seshat requests the YouTube permissions needed to upload and manage videos and read channel information for the operator's own YouTube channel.

What is stored

Google sign-in tokens, the operator's own scheduled and published content, and standard application logs. All of it is stored locally on hardware owned and controlled by the operator.

What is never done

Seshat does not sell, share, or transfer Google user data to any third party. It does not use Google user data for advertising, analytics, or tracking. It uses that data only to upload the operator's own videos.

Google API Services User Data Policy

Seshat's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

The operator can revoke access at any time at myaccount.google.com/permissions, which makes any stored tokens unusable. Requests about stored data can be made at any time.
